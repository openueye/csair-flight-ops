# 航班运行延误分析与风险评分

## 1. 目标

面向运行控制场景回答三个问题：

1. 延误发生在哪里、集中在什么时段、由什么原因造成？
2. 在只有计划信息时，能否提前识别高风险航班？
3. 当起飞延误已知时，能否用风险评分支持恢复优先级排序？

## 2. 数据与口径

- 航班数据：Kaggle 公开数据集 *Airline Flight Delay Dataset (100K Records)*（`kesinisoujanya`），BTS 派生 2018 年样本；实际文件 1,048,575 行，覆盖 2018-01-01 至 2018-02-26。
- 机场坐标：OurAirports `airports.csv`，按 IATA 代码关联美国机场。
- 完成航班：`CANCELLED=0`、`DIVERTED=0`、`ARR_DELAY` 非空。
- 延误：到达延误 > 15 分钟。
- 时间切分：训练 2018-01-01–02-09（712,402 行），验证 02-10–02-17（141,588 行），测试 02-18–02-26（165,693 行）。测试集不参与拟合或阈值选择。
- 目标编码只在训练期内拟合；训练行使用 5 折 out-of-fold，验证/测试使用全训练期映射，避免目标泄漏。

## 4. 预测模型

### 4.1 Pre-flight（仅计划信息）

特征：月/日/星期/时段、计划离港时刻、计划飞行时间、距离、承运人/机场/航线/时段的历史延误率与流量（训练期拟合，OOF 编码）。

| 指标 | 测试集 |
| --- | ---: |
| ROC-AUC | 0.580 |
| PR-AUC | 0.248 |
| Brier | 0.173 |
| 验证集最优 F1 阈值 | 0.164 |
| 该阈值下 Precision / Recall / F1 | 0.254 / 0.284 / 0.268 |
| Top 10% 实际延误率 | 25.94% |
| Top 10% lift（基线 20.78%） | 1.25× |

结论：仅靠计划信息与历史统计，提前预测的上限有限；需要天气、流控/NAS、飞机尾号与机组排班等数据才能显著提升。

### 4.2 At-gate（起飞延误已知）

在相同特征上加入 `DEP_DELAY`（pushback 后已知），用于“恢复优先级/风险评分”，不是提前预测。

| 指标 | 测试集 |
| --- | ---: |
| ROC-AUC | **0.925** |
| PR-AUC | **0.870** |
| Brier | 0.062 |
| 验证集最优 F1 阈值 | 0.475 |
| 该阈值下 Precision / Recall / F1 | 0.909 / 0.700 / 0.791 |
| Top 10% 实际延误率 | **99.75%** |
| Top 10% lift（基线 20.78%） | **4.80×** |

![ROC / PR](../outputs/figures/roc_pr_curves.png)

![校准曲线](../outputs/figures/calibration.png)

![特征重要性](../outputs/figures/feature_importance.png)

解读：

- 起飞延误是到达延误的主导信号；Top 10% 风险航班的实际延误率接近 99.75%，可用于登机口/运行席的恢复排序。
- 由于 `DEP_DELAY` 在 pushback 后才已知，这个评分不应用于“提前一天”的航班筛选；它回答的是“已经晚了，后续还会不会继续晚、优先处理谁”。
- 特征重要性显示承运人历史延误率、机场×时段、计划离港时刻是 pre-flight 的主要信号；这也解释了为什么缺少天气/流控时 AUC 偏低。

## 5. 对运控业务的启示

1. **监控对象**：承运人（B6）、机场（ORD）、航线（SAN–PHX）和周五晚高峰应进入重点监控清单。
2. **恢复策略**：晚到飞机 + 承运人原因占约 70%，优先做飞机周转、备份运力与保障资源调度；NAS/流控需要提前调整计划。
3. **数据建设**：要把 pre-flight AUC 从 0.58 提升到可用水平，必须接入天气、NAS/流控、飞机尾号与机组排班数据；仅靠历史统计不够。
4. **风险评分定位**：at-gate 评分适合“已起飞延误后的恢复优先级”，不适合作为提前预测模型对外表述。

## 6. 局限

- 样本仅 2018-01-01–02-26，且为公开样本；不能代表全年、其他年份或航司实际运行。
- 未接入天气、NAS/流控、飞机尾号、机组排班；pre-flight 模型因此偏弱。
- 延误原因字段只覆盖部分延误航班；原因份额是“有归因延误分钟”的份额。
- 机场地图为经纬度散点，未叠加行政边界；用于热点识别，不用于精确制图。
- 测试期延误率（20.78%）高于训练期（17.28%），存在时间漂移；模型指标应按测试期解读。
